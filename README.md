# Combat Notes

A local-first martial arts video notebook built as a static web app for GitHub Pages.

## Run locally

Serve the folder with any static server, for example `python3 -m http.server 8000`, then open `http://localhost:8000`.

## Deploy

In GitHub repository settings, open **Pages**, choose **Deploy from a branch**, and select the root of your default branch.

All notebook data is stored in the browser. Use **Settings → Export backup** to keep a portable copy.
